Приватность по умолчанию

Сообщения, файлы и черновики шифруются на устройстве. Сервер видит, кому доставить данные, но не их содержание.

  • Регистрация без телефона, почта — по желанию
  • Кто видит, что вы в сети, время захода и кто может звонить — с исключениями
  • Режим призрака: никто не видит, что вы в сети и когда заходили, отметки о прочтении не отправляются
  • Список устройств и выход из всех чужих сеансов одним нажатием
  • Удаление аккаунта со всеми данными — даже без входа в приложение
  • Открытый исходный код под GPL-3.0 — на GitHub
  • Ключи восстанавливаются паролем, ключом восстановления или с другого устройства — переписка не теряется

Боты и API

Создайте бота в настройках и управляйте им из своей программы: SDK для Node.js, long polling или вебхуки.

  • Переписка с ботами тоже зашифрована — у бота свой ключ
  • Команды бота подсказываются прямо в поле ввода
  • Кнопки под сообщениями — выбор тарифа, меню, ссылки на оплату
  • Боты присылают фото, видео и файлы — тоже в зашифрованном виде
  • Токен открывает только Bot API и только чаты, куда бота добавили
  • Удалили бота — его чаты исчезают вместе с перепиской
