# FrontierX для iPhone и iPad

Нативное приложение-оболочка (Swift, WKWebView) вокруг веб-клиента FrontierX —
того же, что открывается в браузере и внутри приложений для Android и
компьютера. Чаты, ключи шифрования и все функции живут в веб-клиенте и
обновляются сами; приложение добавляет разрешения (микрофон, камера,
геопозиция, фото), уведомления, сохранение файлов и открытие внешних ссылок.

## Собирается только на macOS

Приложения для iOS собираются только на Mac: нужен Xcode (15 или новее),
который есть только для macOS. На Linux и Windows собрать iOS-приложение
нельзя — ни этот проект, ни любой другой.

1. Установите Xcode из App Store и один раз откройте его.
2. Установите XcodeGen: `brew install xcodegen`
3. Сгенерируйте проект и откройте его:

   ```sh
   cd apps/ios
   xcodegen generate
   open FrontierX.xcodeproj
   ```

4. В Xcode: цель **FrontierX** → **Signing & Capabilities** → выберите свою
   команду (Apple ID). При необходимости поменяйте Bundle Identifier
   (`com.frontierx.ios`) на свой уникальный.
5. Подключите iPhone кабелем, выберите его сверху и нажмите **Run** (⌘R).

## Установка на телефоны

- **Бесплатный Apple ID**: приложение ставится на свои устройства прямо из
  Xcode, но работает 7 дней, потом его нужно собрать заново.
- **Apple Developer Program** (99 $ в год): установка через TestFlight
  (Product → Archive → Distribute App → TestFlight) для до 10 000 человек
  или публикация в App Store.
- Файл `.ipa`, выложенный на сайт, iPhone установить не даст — только через
  TestFlight, App Store или Xcode.

## Уведомления

Пока приложение открыто (и несколько секунд после сворачивания), новые
сообщения показываются системными уведомлениями. Для уведомлений при закрытом
приложении нужен Apple Push Notification service: ключ APNs из аккаунта
Apple Developer и отправка пушей с сервера — это следующий шаг.

Уже сейчас уведомления при закрытом приложении работают у веб-версии,
установленной из Safari: **Поделиться → На экран «Домой»** (iOS 16.4 и новее).

## Что внутри

- `FrontierX/AppDelegate.swift` — запуск, уведомления, переход в чат по нажатию.
- `FrontierX/WebViewController.swift` — WKWebView: разрешения только для
  `frontierx.zkito.fun`, внешние ссылки открываются в Safari, загрузки
  сохраняются через меню «Поделиться», цвет статус-бара следует теме.
- `FrontierX/NativeBridge.swift` — `window.FrontierXNative` для веб-клиента
  (платформа `ios`, уведомления, состояние фокуса).
- `project.yml` — описание проекта для XcodeGen (версия, разрешения, иконка).
